# DevFlow

DevFlow is a full-stack project management platform designed for developers and development teams.

## 🚀 Features

- User authentication and authorization
- Project management
- Kanban boards
- Task management
- Team collaboration
- Real-time notifications
- GitHub integration
- Project analytics
- iOS application

## 🛠️ Technologies

### Frontend
- Angular
- TypeScript
- HTML
- CSS

### Backend

- Spring Boot

### Databases

- NoSQL

### Mobile

- SwiftUI
